# Utatane

Utatane is an open-source, native macOS baseware for Ukagaka (伺か). It runs ghosts: desktop characters with dialogue, shells, balloons, reactions, and animations. Compatibility is under active development and is not identical to SSP.

Official name: Utatane / 転寝
Supported OS: macOS 14 or later, Apple Silicon and Intel
License: MIT
Source code: https://github.com/opera7133/Utatane
Releases: https://github.com/opera7133/Utatane/releases
