Utatane / 転寝

伺かをmacOSで動かすための本体アプリです。

今風にしてみたページもあります （日本語 / English / 简体中文 / 繁體中文 / 한국어）

まだ開発中です。既存ゴーストとの互換性を地道に増やしています。SSP全部入りではありません。 通常リリースを小刻みに公開していますが、安定性を保証する区分ではありません。

Utataneをダウンロード （最新バージョン: 取得中...）

動作環境

  • macOS 14以降
  • Apple Silicon / Intel Mac

だいたいできること

  • 複数キャラクター、SERIKOアニメーション、着せ替えの表示
  • SakuraScriptによる会話、選択肢、リンクの再生
  • クリック、ダブルクリック、撫で、ホイールなどのマウス操作
  • NARや、展開済みSSPフォルダからのゴースト・バルーンの取り込み
  • YAYA(文) / KAGARI / SHIOLINK(MiyoJS等) / 里々 / 華和梨 / 美坂 / 灯 / ese-shiori / 偽栞 / 忍を使うゴーストのネイティブ実行
  • ゴーストのネットワーク更新、SSTP、RSS / Atom、HEADLINE/2.0
  • 日本語、英語、中国語（簡体・繁体）、韓国語の画面表示

◎: 代表的な基準、○: 基本対応、△: 条件付き・限定的

Utatane独自機能

  • Materia付属の「さくら」を、対応する会話データの解析によりWineなしで実行
  • OpenAI Realtime APIまたは互換APIを使ったリアルタイム音声会話（実験的）
  • ゴーストのAI連携と、外部ツールから会話・操作できる同梱MCPサーバー（実験的）

まだ無理なこと

  • 一般のWindows向けSHIORI / SAORI / プラグインDLLやexeのmacOSネイティブ実行（一部はWine設定で利用可能）
  • Windows固有のFMO
  • 一部のSakuraScript、SERIKO、着せ替え定義
  • SSPの修復モードや、別配布シェルなどをまとめて扱うネットワーク更新

ゴーストによっては表示、文字コード、イベントの互換性に問題があります。

使い方

  1. Releasesから最新リリースの Utatane-macOS.zip をダウンロード
  2. ZIPを展開し、Utatane.appを「アプリケーション」フォルダへ移動
  3. Utataneを起動

最初から同梱ゴースト「りあ」と専用バルーン「Ria」を利用できます。

初回起動でmacOSに止められた場合

現在の配布版は未署名です。一度起動を試してから、「システム設定」→「プライバシーとセキュリティ」で起動を許可してください。

もしくは、アプリケーションフォルダで sudo xattr -rc Utatane.app を実行してください。

なお、GitHub Actionsによるビルド時にVirusTotalでの自動検査を実施しており、各Releasesページのリリースノートに検査結果およびレポートへのリンクを掲載しています。気になる方はご確認ください。
