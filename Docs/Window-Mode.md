# ウィンドウモード

ウィンドウモードは、デスクトップ上に個別表示しているゴーストのサーフェスとバルーンを、通常のmacOSウィンドウ内へまとめる機能です。配信・画面収録ソフトでウィンドウ単位に取り込みたい場合や、作業用デスクトップとゴーストの表示を分けたい場合に使えます。

## 表示方式を選ぶ

「Utatane設定」→「一般」→「ウィンドウモード（実験的）」の「表示方式」から選びます。アプリの「操作」メニュー、ゴーストの右クリックメニュー、ウィンドウモード自身の操作メニューからも同じ設定を変更できます。

- **使用しない／切**: サーフェスとバルーンを従来どおりデスクトップ上へ個別表示します。
- **全ゴーストをまとめて1枚**: 起動中のすべてのゴーストを1枚のウィンドウへ表示します。
- **ゴーストごとに1枚**: メインゴーストと呼び出したゴーストを、それぞれ別のウィンドウへ表示します。

選択した方式と、通常表示・共通ウィンドウ・ゴースト別ウィンドウでの位置は別々に保存されます。モードを切り替えると、それぞれで最後に調整した位置へ戻ります。

起動時に指定する場合は、次のオプションを利用できます。

```text
--windowmode
--windowmode=shared
--windowmode=perghost
```

`--windowmode`だけを指定した場合は、最後に選んだウィンドウモードの表示方式を使います。

## ウィンドウを操作する

ウィンドウ内を右クリックするか、枠なし表示でポインタを入れたときに現れる操作ボタンからメニューを開けます。

- ウィンドウ枠の表示・非表示
- 全画面表示（`F11`、解除は`Esc`）
- 白、灰、黒、現在のデスクトップ壁紙から背景を選択
- 背景を含むPNG、または背景を透過したPNGとしてスクリーンショットを保存
- ウィンドウモードの表示方式を変更
- ウィンドウを閉じる（`Control-W`）

共通ウィンドウを閉じるとUtataneを終了します。ゴーストごとのウィンドウを閉じると、そのゴーストだけを終了します。最小化した場合は、ウィンドウ内のサーフェスとバルーンも一緒に隠れます。

デスクトップ壁紙はウィンドウ内のサーフェス表示領域へ合わせて拡大・配置します。発話履歴を統合しても、履歴部分を含むウィンドウ全体を基準にはしません。

## 発話履歴

アプリまたはゴーストの「発話履歴」、もしくはSakuraScriptの`\![open,backlogviewer]`から開けます。話者、表示時のサーフェス、時刻、実際に表示された文章を記録し、同じ発話の開始と終了を枠の形で示します。

設定の「発話履歴をウィンドウ内に表示」が有効な場合、ウィンドウモードでは履歴を下部へ固定表示します。履歴を初めて開いたときは、サーフェス表示領域をできるだけ保ったままウィンドウを縦に広げます。壁紙は上側だけに表示し、履歴部分は読みやすい単色背景になります。

この設定を無効にするか、ウィンドウモードを使用しない場合は、発話履歴を独立したウィンドウで表示します。

履歴はゴーストごとに保持し、Utataneを終了すると消去します。ゴースト側は`\__v[disable]`で記録を止め、`\__v[alternate,...]`で履歴用の文章を指定できます。

## macOS上の違いと制約

- ウィンドウモードは実験的な機能です。すべてのシェル、バルーン、SAORIでSSPと同じ結果になることを保証するものではありません。
- 統合した発話履歴はmacOS向けにウィンドウ下部へ固定します。SSPのように履歴パネルだけをウィンドウ端へ移動する操作はありません。
- 設定、入力欄、カレンダーなど、サーフェスとバルーン以外の補助ウィンドウは統合しません。
- デスクトップ壁紙の読み取りに失敗した場合は単色背景へフォールバックします。
- スクリーンショット保存はウィンドウモードの操作メニューから行います。通常表示の複数ウィンドウを1枚へまとめる機能ではありません。
