# 保存場所とバックアップ

## コンテンツの場所を開く

標準の追加コンテンツは `~/Library/Application Support/Utatane` 配下に保存します。「機能」→「コンテンツ管理」からコンテンツフォルダをFinderで開けます。個別の項目はエクスプローラのFinder表示から確認できます。

「設定」→「コンテンツ」で読み込みフォルダやインストール先を追加・変更している場合は、そのフォルダも確認してください。すべてのコンテンツが標準フォルダ内にあるとは限りません。

## 何を保存しているか

| 種類 | 保存内容 |
| --- | --- |
| ゴーストのフォルダ | 辞書、画像、追加シェルなど。ゴースト自身の名前・学習・会話の保存データが含まれる場合があります |
| 本体の設定 | 起動方法、表示設定、選択履歴、コンテンツの読み込み先など。macOSの設定保存機構を使います |
| APIキー | macOS Keychain。コンテンツフォルダのコピーだけでは移せません |
| 発話履歴 | 起動中の履歴。Utataneを終了すると消去します |

キャラクターとバルーンの位置、使用するシェルとバルーンはゴーストごとに復元します。ウィンドウモードの配置は通常表示と別に保持します。

## コンテンツをバックアップする

1. 保存したいコンテンツのフォルダをFinderで確認します。
2. ゴーストが保存処理を終えるよう、Utataneを終了します。
3. 標準コンテンツフォルダと、自分で追加した読み込みフォルダを別の場所へコピーします。

これはコンテンツのバックアップです。本体設定とKeychainを含むMac全体の移行・復元には、Time MachineなどmacOSのバックアップも利用してください。

アプリ更新時に `Utatane.app` を置き換えることと、追加コンテンツを削除することは別です。ゴーストをアンインストールする前には、必要な保存データを残してください。
