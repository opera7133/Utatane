# メニューとショートカット

キャラクターの右クリックメニューと、画面上部のメニューバーから本体機能を開けます。ゴースト独自のメニューはダブルクリックなどから開く場合があります。

MenuBarのUtataneアイコンは、左右どちらのクリックでも操作メニューを開きます。ランダムトーク、ゴースト変更、Surface再表示、発話履歴、設定、ヘルプ、終了をここから選べます。通知用の吹き出しが出ている間は、左クリックが通知の選択、右クリックが操作メニューになります。

DockにUtataneを表示せず動かしたい場合は、「設定」→「一般」の「Dockにアプリアイコンを表示」を無効にしてください。非表示にしてもMenuBarのアイコンは残ります。

## メニューバーの主な操作

| 操作 | ショートカット |
| --- | --- |
| 設定を開く | Command + , |
| エクスプローラ | Command + E |
| カレンダー | Command + Shift + K |
| IP Messenger | Command + Shift + M |
| ゴーストを変更 | Command + Shift + G |
| Surfaceを再表示 | Command + Shift + R |
| 発話履歴 | Command + Shift + H |
| Utataneヘルプ | Command + ? |

ウィンドウモードの全画面表示は `F11`、解除は `Esc` です。Macのキーボード設定によってはファンクションキーに `Fn` の併用が必要です。

## 右クリックメニューから探す

| 入口 | 主な用途 |
| --- | --- |
| ネットワーク更新 | コンテンツの更新 |
| アンインストール | 管理対象コンテンツの削除 |
| ヘッドライン / プラグイン | ニュースや拡張の利用 |
| 機能 | カレンダー、IP Messenger、エクスプローラ、発話履歴。音声・ウィンドウモード・コンテンツ管理・復旧操作は各サブメニュー |
| 設定 | 本体・ゴーストの設定、設定画面への移動、配置プリセット |
| ゴースト・呼び出し・シェル・着せ替え・バルーン | 表示するコンテンツの選択 |
| 情報 | コンテンツのREADME、Utataneヘルプ、SHIORI読み込み診断、開発用パレット |

項目は、現在のゴースト、呼び出したゴースト、インストール済みコンテンツに応じて変わります。
