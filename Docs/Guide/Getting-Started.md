# はじめてのUtatane

Utataneは、伺かのキャラクターをMacのデスクトップで動かすためのアプリです。キャラクターを眺めたり、クリックして反応を楽しんだりできます。

## 最初に知っておく言葉

| 名前 | 意味 |
| --- | --- |
| ゴースト | キャラクター、会話、反応などをまとめたデータ |
| シェル | キャラクターの見た目。追加シェルや着せ替えがあるものもあります |
| バルーン | 会話を表示する吹き出し |
| ベースウェア | ゴーストを動かす本体アプリ。UtataneやSSPなど |
| NAR | ゴーストなどを配布するためのパッケージファイル |

ゴースト「りあ」とバルーン「Ria」は同梱しています。SHIORIモジュールの初回導入が終われば、ゴーストやバルーンを別に追加せず遊べます。

初回起動時にSHIORIモジュールの導入画面が開いたら、YAYA 6と里々を導入してください。ゴーストやバルーンのファイルは変更しません。両方が既に導入済みなら、カタログに接続できない時もそのまま起動できます。未導入の場合はネット接続を確認して「再読み込み」を試すか、[手動導入の手順](https://github.com/opera7133/utatane-modules)を確認してください。手動導入後はUtataneを再起動します。

別のゴーストも追加できます。ただし、Windows向けのすべての機能が動くわけではありません。

## インストールする

1. [リリースページ](https://github.com/opera7133/Utatane/releases)から `Utatane-macOS.zip` をダウンロードします。
2. ZIPを展開し、`Utatane.app` を「アプリケーション」フォルダへ移動します。
3. Utataneを起動します。macOS 14以降のApple Silicon・Intel Macに対応しています。

未署名の配布版でmacOSが起動を止める場合は、一度起動を試したあと、「システム設定」→「プライバシーとセキュリティ」で開くことを許可します。入手元が公式のリリースであることを確認してください。

## 最初の操作を試す

1. キャラクターをドラッグして、置きたい場所に移動します。
2. キャラクターをダブルクリックしたり、頭などを撫でたりして反応を試します。反応はゴーストごとに異なります。
3. キャラクターを右クリックして、本体側のメニューを開きます。
4. 会話中に選択肢が現れたらクリックします。

文字が小さければ「設定」→「喋り / バルーン」の文字サイズを、キャラクターが大きければ「設定」→「ゴーストごとの設定」の倍率を調整します。

続きは[ゴーストと遊ぶ](Basic-Operations.md)と[コンテンツを管理する](Content.md)を読んでください。見えない・反応しない場合は[困ったとき](../Support/Troubleshooting.md)を確認できます。

## ゴースト切り替え時のモジュール導入（次回版）

必要なSHIORI・既知のSAORIが未導入なら、切り替える前に一覧を表示します。カタログにこのMac用の配布物があるものは「まとめてダウンロード」で導入できます。カタログ未掲載・手動導入のみ・このMacでは利用不可の項目は、理由を分けて表示します。

手動対応が必要なものが混ざっていても、導入できる分だけ先にダウンロードできます。途中で失敗した場合は、完了したものを残して、再試行時には不足分だけ取得します。導入と再確認が終わるまで、元のゴーストを終了しません。Wineが設定され、必要なWindows DLLが揃っている場合はWineでの起動も選べます。

検出対象はSHIORIの指定、既知の同梱SAORI DLL、里々の`＠SAORI`登録、制作者による必要モジュール宣言です。プラグインはこの依存導入の対象に含めません。任意の辞書処理から動的に生成されるSAORI名までは検出できません。
