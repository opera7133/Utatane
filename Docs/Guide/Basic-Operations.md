# ゴーストと遊ぶ

## 会話とマウス操作

まずはキャラクターをダブルクリックしてみてください。メニューを開いたり、話しかけてきたりするゴーストがあります。頭や手などを撫でると、場所によって反応が変わることもあります。

クリック、ダブルクリック、撫で、ホイールにどう反応するかは、ゴーストごとに違います。無反応でも、そこを触られる予定がなかっただけかもしれません。詳しい遊び方はゴースト自身のメニューやREADMEで確認できます。

バルーンの文章部分をクリックすると会話を早送りできます。会話が終わったあとのクリックでバルーンを閉じます。選択肢やリンクをクリックした場合は、その項目の操作になります。

ゴーストのダブルクリックメニューと、本体の右クリックメニューは別のものです。名前入力、会話内容、ゴースト独自の設定などは、ゴースト側のメニューにある場合があります。

## 移動と表示

キャラクターとバルーンはドラッグして移動できます。キャラクターの移動中は半透明になり、座標と移動量を表示します。配置はゴーストごとに保存します。

縦方向に動かせない場合は「設定」→「ゴーストごとの設定」→「画面下に固定」を確認します。画面端の補正や表示倍率も同じ画面で変更できます。

画面外に移動した場合は、右クリックの「機能」→「復旧操作」→「ウインドウ位置を初期化」を使います。キャラクターが見えず右クリックできないときは、メニューバーの「操作」→「Surfaceを再表示」を試します。

## ゴースト・シェル・バルーンを変える

右クリックメニューからゴースト、シェル、バルーンを選びます。「着せ替え」は、現在のシェルに対応する定義がある場合に表示します。[エクスプローラ](Content.md)からも切り替えられます。

- **切り替え**: 現在のゴーストを閉じて、別のゴーストを表示します。
- **呼び出し**: 現在のゴーストを残したまま、別のゴーストも表示します。

呼び出したゴーストでは、右クリックメニューの一部を省略しています。

## 会話を止める・終了する

右クリックの「機能」→「復旧操作」→「バルーンを閉じる」から会話の再生を止められます。ゴーストを閉じる操作と「すべて終了」は別です。「すべて終了」はUtatane全体を終了します。

## ゴースト自身の説明を読む

右クリックの「情報」→「README」から、ゴースト・シェル・バルーンの説明を開けます。本体側の説明は「情報」→「Utataneヘルプ」です。ゴースト固有の反応や利用条件は、作者のREADMEを優先して確認してください。

表示を1枚のウィンドウにまとめたい場合は[ウィンドウモード](Window-Mode.md)を参照してください。
