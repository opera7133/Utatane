# IP Messenger

Utataneは、同じLAN上のSSPやIP Messengerと平文メッセージを送受信できます。別のメッセンジャーアプリを起動しておく必要はありません。

## 使い方

1. 「本体設定」→「ネットワーク」を開きます。
2. 「IP Messenger互換モードを利用」をオンにします。
3. 必要に応じて表示名とグループ名を変更します。
4. 「操作」メニュー、またはゴーストの右クリックメニューの「機能」から「IP Messenger」を開きます。
5. 同じLAN上で見つかったメンバーを選び、メッセージを送ります。

ゴーストからは `\![open,messenger]` でも画面を開けます。受信したメッセージはIP Messenger画面に表示され、画面が閉じている場合は自動的に開きます。起動中のゴーストがいる場合、本文をSakuraScriptとしてバルーンとサーフェスでも再生します。通常の文章もそのまま発話として表示されます。

LANから届いた内容がそのままmacOSやゴーストの操作にならないよう、受信時は発話、サーフェス、バルーン、文字装飾、待機などの表示用命令だけを再生します。URL・ファイルを開く命令、外部通信、インストール・更新、イベント送信、位置やウィンドウ状態を変更する命令などは無視します。

## ネットワーク設定

既定では、UDP 2425番ポートとブロードキャスト先 `255.255.255.255` を使います。Utataneは利用中のネットワークインターフェースに対応するブロードキャスト先も自動的に使うため、通常は変更する必要はありません。ルーターやmacOSのファイアウォールでUDP通信が遮断されていると、メンバーを発見できません。

IP Messenger for macOSなどが同じポートをすでに使用している場合、Utataneは空いている返信用ポートへ自動的に切り替えます。探索先は設定したポートのままで、同じMac上の相手にはループバック経由でも在席通知を送るため、併用できます。

ブロードキャスト先には、ネットワーク環境に応じたIPv4のブロードキャストアドレスを複数指定できます。カンマ、空白、または改行で区切ってください。

初回利用時にmacOSからローカルネットワークへのアクセス許可を求められた場合は、同じLAN上のメンバーを探すために許可が必要です。

プロトコル内部の識別子にはmacOSのユーザー名やコンピュータ名を使いません。相手の一覧には、本体設定で指定した表示名とグループ名が表示されます。

## 現在の対応範囲

- ログイン・ログアウトと在席メンバーの発見
- UTF-8対応相手とのUTF-8通信と、従来相手とのShift_JIS通信
- 1対1の平文メッセージ送受信
- 受信した本文の、安全な表示用SakuraScriptとしての再生
- 受信確認と未確認時の再送
- 表示名とグループ名、ポート、ブロードキャスト先の設定

IP Messenger v2の暗号化、ファイル添付、IPv6、メンバー管理サーバー、オフライン配送には対応していません。メッセージは暗号化されないため、信頼できるLANで利用してください。
