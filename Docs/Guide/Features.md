# カレンダー・ニュース・拡張

## カレンダー

右クリックの「機能」→「カレンダー」、またはメニューバーの「操作」→「カレンダー」から開きます。日付や予定を確認・編集できます。予定への反応はゴースト側の対応によって異なります。

## RSS / ヘッドライン

右クリックの「ヘッドライン」メニューを使います。RSS / Atomの取得とHEADLINE/2.0センサーを扱えます。「設定」→「ネットワーク」で自動巡回と間隔を変更します。

センサーの追加・管理にはコンテンツのインストールとエクスプローラを使います。`config.txt` 形式はネイティブに扱えますが、独自のWindows DLL型センサーはWineなどの設定が必要な場合があります。

## プラグイン

インストール後、右クリックの「プラグイン」から利用します。プラグインによって、設定や独自メニュー、READMEがあります。

Utataneがネイティブに扱うSHIORI形式やmacOS用モジュールを利用できます。Windows用のプラグインは、NARを追加しただけでは実行できない場合があります。[対応範囲](../Support/Native-SHIORI.md)を確認してください。

## 音楽との連携

「設定」→「一般」→「再生中の曲情報をゴーストに通知」で有効にします。Spotify、ミュージック、ブラウザなど、macOSの「再生中」に表示される曲の変化を通知します。

曲の感想などを話すには、ゴースト側がその通知を扱う必要があります。本体設定だけで、すべてのゴーストが音楽へ反応するようになるわけではありません。

## 生成AI・リアルタイム音声会話

AI用のゴーストや[Realtime音声会話](Realtime-Voice.md)では外部APIまたは対応するローカルAPIへ接続します。設定は「ネットワーク」にあります。通常の辞書型ゴーストを使うためにAPIキーを用意する必要はありません。

Realtime音声会話は「機能」→「音声」→「リアルタイム音声会話…」から開き、「会話を開始」を押して開始します。開始・終了と接続状況は音声会話の画面で確認してください。

## Utatane本体の更新

「機能」→「本体更新をチェック」から新しい配布版を確認できます。ゴーストやシェルなどのネットワーク更新とは別です。

## 配置プリセット

「普段はデスクトップ、配信ではウィンドウにまとめる」といった配置を、名前を付けて保存できます。呼び出したゴーストも一緒に保存します。

1. 右クリックの「設定」→「配置プリセット…」、またはメニューバーの「操作」から開きます。
2. 名前を入力し、「現在の配置を保存」を押します。
3. 戻したいときは一覧から選び、「配置を復元」を押します。

保存した項目は上書き、名前の変更、削除もできます。プリセットを削除しても、ゴーストなどのコンテンツは残ります。

| 保存するもの | 内容 |
| --- | --- |
| コンテンツの組み合わせ | メインと呼び出したゴースト、それぞれのシェル・バルーン |
| 配置 | キャラクターと既に表示したバルーンの位置、ウィンドウモードとウィンドウ枠 |
| 表示設定 | 表示倍率、文字倍率、倍率連動、大きなサーフェスの自動縮小 |

会話や辞書の状態、APIキー、コンテンツ本体は保存しません。会話の巻き戻し機能ではないので、さっき言ったことまで忘れてくれるわけではありません。

復元すると、現在のゴースト一式を保存した構成へ切り替えます。画面構成が変わっていれば、画面内に位置を補正します。

コンテンツを移動・削除した場合は復元できません。必要なコンテンツの存在は切り替え前に確認します。ただし、その後のSHIORI起動に失敗すると、復元途中の構成が残ることがあります。

プリセットはこのMacのUtatane設定に保存されます。別のMacへの持ち運びや、コンテンツの移転を自動追跡する仕組みではありません。
