# 互換性の確認

Utataneで使える機能は、ゴーストのSHIORI、シェルの定義、外部モジュールによって異なります。同じSHIORIを使うゴーストでも、Windows固有の機能や独自SAORIに依存する部分には違いがあります。

## 導入前に確認する

[Utatane NAR検査](https://utatane-validate.wmsci.com/)では、NARに含まれるSHIORIと基本的な対応状況を確認できます。実行前の目安として利用してください。導入後はエクスプローラでゴーストを選び、「互換性を検査」から不足ファイルや未対応命令を確認できます。

検査結果に問題がなくても、会話の分岐や外部プログラムとの連携には実際の操作が必要です。まず次を試すと、普段の利用で困る部分を見つけやすくなります。

1. 起動して会話とメニュー操作を試す
2. クリック・撫で・選択肢が反応するか確認する
3. シェルや着せ替え、バルーンを切り替える
4. 終了して再起動し、名前や設定などの保存内容を確認する
5. 音声・ニュース・ネットワーク更新など、普段使う機能を試す

## SHIORI・SAORIを確認する

YAYA・里々などのmacOS用SHIORIは、モジュールカタログから導入できます。起動できない場合は「SHIORI読み込み診断」で、選択先のファイル、CPUの種類、直近の読み込み結果を確認してください。

SAORIは、ゴーストが音声再生、クリップボード、外部プログラムなどを使うための追加モジュールです。macOS用の互換モジュールがある場合は、共通導入して利用できます。Windows DLLを使う機能にはWineなどの設定が必要な場合があります。

詳しい選択方法、対応モジュール、必要な版は[SHIORI・SAORIの利用](Native-SHIORI.md)を参照してください。YAYA 6から5へ切り替える場合は、同ページの保存データの復元手順も確認してください。

## Materia付属FIRSTを使う場合

対応版の`first.dll`を用意すると、Wineを介さずに実行できます。配置方法は[READMEの導入手順](../../README.md)を参照してください。会話・マウス操作・主要メニューに加え、Todo、通知、天気、メール確認などを利用できます。

Todoと通知は会話メニュー・入力欄から操作します。通知は対象のゴーストを起動している間に表示され、繰り返しやファイルの起動も指定できます。リストは各100件、内容は500文字までです。通知時に開くファイルには絶対パスを指定し、`~/`も利用できます。コマンドライン引数や、カンマ・角括弧・引用符などを含むパスは対応範囲外です。

現在の天気にはmacOSの位置情報とOpen-Meteoを利用します。メール確認はPOP3の`TOP`に対応したサーバーから、最大20件の送信者・件名を取得します。メール本文と削除操作は対象外です。元版のTodo・通知ファイルの移行は今後の対応項目です。

ごみ箱の清掃はログインユーザーのホーム内を、履歴整理とメモリ解放はUtatane自身を対象にします。Macの終了・再起動にはゴーストの確認選択肢と、macOSのオートメーション許可が必要になる場合があります。

## コンテンツのネットワーク更新

旧来の配布サイトとの互換性のため、HTTPの更新URLも利用できます。HTTPでは更新一覧とファイルのMD5照合だけでは通信経路の改ざんを防げないため、信頼できる配布元を利用してください。

HTTPSの証明書検証は有効です。Utatane本体の更新にはHTTPSとSparkleの署名検証を使用します。
