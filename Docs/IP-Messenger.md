# IP Messenger

Utataneは、同じLAN上のSSPやIP Messengerと平文メッセージを送受信できます。別のメッセンジャーアプリを起動しておく必要はありません。

## 使い方

1. 「本体設定」→「ネットワーク」を開く
2. 「IP Messenger互換モードを利用」をオンにする
3. 必要に応じて表示名とグループ名を変更する
4. 「操作」メニュー、またはゴーストの右クリックメニューの「機能」から「IP Messenger」を開く
5. 同じLAN上で見つかったメンバーを選び、メッセージを送る

ゴーストからは `\![open,messenger]` でも画面を開けます。受信したメッセージはIP Messenger画面に表示され、画面が閉じている場合は自動的に開きます。

## ネットワーク設定

既定では、UDP 2425番ポートとブロードキャスト先 `255.255.255.255` を使います。通常は変更する必要はありません。ルーターやmacOSのファイアウォールでUDP通信が遮断されていると、メンバーを発見できません。

ブロードキャスト先には、ネットワーク環境に応じたIPv4のブロードキャストアドレスを複数指定できます。カンマ、空白、または改行で区切ってください。

初回利用時にmacOSからローカルネットワークへのアクセス許可を求められた場合は、同じLAN上のメンバーを探すために許可が必要です。

## 現在の対応範囲

- ログイン・ログアウトと在席メンバーの発見
- UTF-8対応相手とのUTF-8通信と、従来相手とのShift_JIS通信
- 1対1の平文メッセージ送受信
- 受信確認と未確認時の再送
- 表示名とグループ名、ポート、ブロードキャスト先の設定

IP Messenger v2の暗号化、ファイル添付、IPv6、メンバー管理サーバー、オフライン配送には対応していません。メッセージは暗号化されないため、信頼できるLANで利用してください。
