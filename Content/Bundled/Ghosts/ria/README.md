# りあ

Utatane用に作られた、19歳の妹ゴースト。

お兄の作業机の横に適当にいる。話は聞くし、困っていれば最低限は手伝う。
ただし、ずっと機嫌よく相手をするとは限らない。兄妹なのでそのくらいでいいと思う。

## できること

- 2分ほどごとのランダムトーク
- 時間帯、曜日、季節、一部の日付に合わせたトーク
- 大学の課題や買った本など、数日かけて少しずつ進む生活トーク
- 時間帯と起動回数に応じた起動トーク
- 深夜はランダムトークの間隔を長くする
- 起動からの経過時間と、しばらく入力がない状態に合わせたトーク
- 撫でられた回数で少し変わる機嫌と反応
- 直前と同じトークをなるべく避ける
- トークを閉じると通常表情に戻る
- 頭、顔、胸、手、脚のダブルクリック反応
- 頭を撫でる反応
- 左右の長い髪をなぞる「髪さらさら」反応
- 頭や髪でホイールを回したときの反応
- 手をダブルクリックして、時刻・曜日・状態・ランダムトークなどを選ぶ簡易メニュー
- 普段着と外出着の切り替え（自動、普段着固定、外出着固定）
- 散歩やコンビニへ出かけ、しばらくすると戻ってくる外出イベント
- 散歩、コンビニ、本屋、大学への外出を数日間覚え、後の雑談で思い出す
- macOSの位置情報権限を使った現在地の天気確認（操作した時だけ取得）

頭や髪は、マウスカーソルを少し往復させると反応する。

着替えの初期設定は自動。平日の8時から18時までは外出着、それ以外は普段着になる。
手のダブルクリックメニューから固定もできる。
同じメニューから短い外出や現在地の天気確認も選べる。
